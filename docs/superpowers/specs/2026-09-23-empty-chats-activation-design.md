# Empty Chats Activation Design

## Goal

Turn the existing zero-chat state into a welcoming activation moment without adding another onboarding screen.

## Approved screen

- Keep the real Chats shell and bottom navigation.
- Show the approved transparent pixel illustration of two laughing friends.
- Use the positive title `Start your first chat`.
- State the payoff clearly: `Practice a language through real conversations.`
- Keep the primary `Invite a friend` button.
- Hide the floating `+` action only while the chat list is confirmed empty.
- Invite-link users continue to bypass this state and open their resulting chat directly.

## Responsive behavior

The illustration stays decorative, centered, and bounded above the copy. Text may wrap naturally in localized and large-text layouts without crowding the button or bottom navigation.
