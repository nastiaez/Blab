## Finding confirmation

A chat created after the private language-history migration did not receive its initial revision-one language boundary. After its first language change, the new revision became the earliest available boundary, so older completed messages used the newest language despite already having their original completed results saved.

## Scope

- Record the initial private learning-language boundary when a participant joins a new chat.
- Recover that missing initial boundary before a first language change for affected existing memberships.
- Preserve earlier completed language results for both people in a chat; only messages after a switch use the newly selected language.
