# Production notification content extension

BLAB_MESSAGE_V1 uses the approved f3fcb7c expanded renderer (40–45).
NotificationAccount independently checks the installation's shared account/epoch/preview
state before displaying sender, group or body. No networking, credentials, cache writes
or navigation authority exist here. Compact communication transformation belongs to the
Runner local adapter and NotificationService, not this content extension.
